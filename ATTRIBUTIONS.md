# Artwork and icon sources

The hero banners, Mallesh monogram, terminal introduction, footer, stack tile layouts, and snapshot layouts are original artwork created for this profile. The source scripts are included so Mallesh can edit and regenerate them.

Technology symbols in `assets/icons/` and embedded in `assets/stack/` come from [Simple Icons](https://github.com/simple-icons/simple-icons), revision [`777807a262bb7384ff406fd4b35fdcd02e9514c3`](https://github.com/simple-icons/simple-icons/tree/777807a262bb7384ff406fd4b35fdcd02e9514c3): Node.js, Express, TypeScript, MySQL, Drizzle, React, Tailwind CSS, and React Query. The upstream SVG paths were preserved; the tiles apply theme-appropriate colors and original framing.

Simple Icons distributes its collection under CC0 1.0. The full upstream license is in [docs/simple-icons-LICENSE.md](./docs/simple-icons-LICENSE.md). Brand names and symbols identify technologies; their respective owners retain any trademark rights.

The shipped GIF was rasterized with the locally installed DejaVu Sans Mono font. No font file is included or loaded remotely. SVG artwork uses system font fallbacks.

The public GitHub snapshot is derived from the GitHub REST API and records its collection date and scope in [assets/github-stats.json](./assets/github-stats.json).
